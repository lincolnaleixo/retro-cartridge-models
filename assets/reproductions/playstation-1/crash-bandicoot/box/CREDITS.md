The bundled `artwork-sources.json` identifies this edition's selected references. `artwork-provenance.json` records source and output hashes, source pixel dimensions and restoration operations. `artwork-embedding-report.json` verifies the exact prepared images applied to each print surface.

Deterministic original-print noise reduction, matching classic vector branding, and bounded single-ink contour restoration. The original four-part SCUS-94900 K-A print set and all game illustrations are retained. The matching classic 1994 wordmark replaces only worn branding. NTSC U/C and TM text is reproduced exactly, using a documented approximate Arial Bold face rather than a verified original production font. Enlargement supplies antialiased lettering but does not recover new photographic detail. Original game screenshot detail remains source-limited. Sony official timeline artwork was researched but rejected as a 400×400 jewel-case product image with lower effective cover detail. Modern PlayStation wordmarks were rejected because their letter shapes differ. The original four-part SCUS-94900 K-A set and all game illustrations remain. Matching classic 1994 wordmarks replace only worn console branding. NTSC U/C and TM copy is reproduced exactly using approximate Arial Bold, not a verified original production font. Original rear copy and screenshot detail remain source-limited; output enlargement does not recover new photographic detail. Printed inner ribbed design remains artwork; only unprinted outside trim loses crease glare. Colors are visual estimates. Prepared-face resolution limits fine lettering and image detail; local cleanup cannot establish exact original print colors or recover unseen design information. No generated replacement game illustration or invented lettering is asserted.

## Geometry references

The independent neutral playstation-1 box release supplies the construction. Its relevant sources and measurement caveats are retained in `geometry-reference-evidence.json`. The envelope uses midpoint values from CMC assembly inspection ranges, not proof of the original Sony supplier. Fine molded features, booklet leaves and paper-fit dimensions are approximate. Clear plastic rendering depends on the importing engine.
