# Reproductions

Game-specific media are grouped by console and game:

- SNES: [Super Mario World](snes/super-mario-world/README.md)
- Mega Drive: [Sonic the Hedgehog](mega-drive/sonic-the-hedgehog/README.md)
- PlayStation 1: [Crash Bandicoot](playstation-1/crash-bandicoot/README.md)
- Nintendo 64: [Super Mario 64](nintendo-64/super-mario-64/README.md)
- NES: [Super Mario Bros.](nes/super-mario-bros/README.md)

Each game directory holds its records, version history and previews. Download links in the game's README provide the editable Blender source and self-contained GLB. Game artwork, trademarks and source photography retain their original third-party rights; see each model's credits and packaged notices. Source attribution and a maintainer's request do not grant rights in those elements.

## Game boxes

Each game now has an independently versioned articulated `box/` subfolder containing its packaging, previews and release records. The cartridge or disc remains in the parent game folder.
