# Templates

Neutral media templates are grouped by console:

- [SNES cartridge](snes/README.md)
- [Mega Drive cartridge](mega-drive/README.md)
- [PlayStation 1 CD](playstation-1/README.md)

Each directory holds the model's records, version history and previews. Download links in the model's README provide the editable Blender source and self-contained GLB, with the original license and credits.
