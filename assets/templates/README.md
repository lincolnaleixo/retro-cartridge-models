# Templates

Neutral media templates are grouped by console:

- [SNES cartridge](snes/README.md)
- [Mega Drive cartridge](mega-drive/README.md)
- [PlayStation 1 CD](playstation-1/README.md)
- [Nintendo 64 NTSC-U/C cartridge](nintendo-64/README.md)
- [NES early five-screw cartridge](nes/README.md)

Each directory holds the model's records, version history and previews. Download links in the model's README provide the editable Blender source and self-contained GLB, with the original license and credits.

The templates have unprinted artwork surfaces. The Nintendo 64 shell retains an approximate molded Nintendo wordmark; it and the underlying hardware designs remain outside the original-contributions license. See each template's credits for reference measurements and limits.
