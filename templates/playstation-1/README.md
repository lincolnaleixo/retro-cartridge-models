# PlayStation 1 CD template

This folder is the library entry for [`playstation-1`](../../assets/playstation-1/README.md). The versioned asset record remains in `assets/playstation-1/` so existing downloads and RetroLife integrations stay compatible.

- [Model documentation](../../assets/playstation-1/README.md)
- [Release history](../../assets/playstation-1/CHANGELOG.md)
- [Public 3D gallery](https://lincolnaleixo.github.io/retro-cartridge-models/#playstation-1)
- [Published packages](https://github.com/lincolnaleixo/retro-cartridge-models/releases?q=playstation-1-v)

Run `python3 tools/build_library.py` from the repository root to download and verify the current release. The offline library places its editable Blender source, GLB export, previews, credits, exact release ZIP and manifest together in `dist/library/templates/playstation-1/`.

See the [library instructions](../../README.md#organized-library) for custom output and cache paths. Read the packaged license and credits before reuse; this folder classification does not change any rights grant.
