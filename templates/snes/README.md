# SNES cartridge template

This folder is the library entry for [`snes-ntsc-u`](../../assets/snes-ntsc-u/README.md). The versioned asset record remains in `assets/snes-ntsc-u/` so existing downloads and RetroLife integrations stay compatible.

- [Model documentation](../../assets/snes-ntsc-u/README.md)
- [Release history](../../assets/snes-ntsc-u/CHANGELOG.md)
- [Public 3D gallery](https://lincolnaleixo.github.io/retro-cartridge-models/#snes-ntsc-u)
- [Published packages](https://github.com/lincolnaleixo/retro-cartridge-models/releases?q=snes-ntsc-u-v)

Run `python3 tools/build_library.py` from the repository root to download and verify the current release. The offline library places its editable Blender source, GLB export, previews, credits, exact release ZIP and manifest together in `dist/library/templates/snes/`.

See the [library instructions](../../README.md#organized-library) for custom output and cache paths. Read the packaged license and credits before reuse; this folder classification does not change any rights grant.
